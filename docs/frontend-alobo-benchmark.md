# Benchmark tham chieu theo trai nghiem ALOBO

Ngay cap nhat: 2026-04-15

## Bang benchmark

| Khu vuc | Pattern can hoc theo | Ap dung vao SportCourt |
|---|---|---|
| Home | Tim san nhanh ngay dau trang, CTA ro | Quick search (dia diem, sport, ngay, gio) dieu huong vao listing |
| Listing | Card gon, scan nhanh, filter/sort de hieu | Discover card + filter sport/price + sort + clear all |
| Slot grid | Nhin lich theo court va thoi gian rat truc quan | BookingGrid theo hang court/cot time slot + legend mau |
| Checkout | Summary ro + trang thai thanh toan ro | Checkout panel + payment status + retry/polling |
| My bookings | Group theo status va action theo context | Tabs upcoming/completed/cancelled + detail + actions |
| Mobile UX | Drawer/bottom sheet cho filter, sticky CTA | Mobile filter drawer + summary card; bottom nav chi hien o trang dieu huong chinh (discover/account), an trong booking/payment flow |

## Nguyen tac benchmark
- Khong copy giao dien 1:1.
- Uu tien hoc logic trai nghiem: it buoc, ro trang thai, CTA de thay.
- Moi thay doi UI phai map duoc vao conversion cua booking funnel.
- Focus mode cho booking/payment: an bottom nav de tranh user roi flow giua chung.
