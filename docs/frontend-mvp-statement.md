# Frontend MVP Statement (ALOBO-inspired)

Ngay cap nhat: 2026-04-15

## Pham vi ban phat hanh MVP
- Home public booking-first.
- Venue listing (discover) voi search/filter/sort.
- Venue booking grid: xem slot trong, chon khung gio.
- Checkout + payment status.
- Login/Register.
- My bookings (upcoming/history/detail).

## Muc tieu kinh doanh
- Giup user hoan tat dat san nhanh nhat co the.
- Giam so buoc va giam ly do roi flow truoc checkout.
- Tao trai nghiem mobile-first de dat san bang dien thoai la chinh.

## North-star journey
Tim san -> xem slot trong -> chon slot -> dang nhap (neu can) -> thanh toan coc/full -> xem xac nhan booking.

## Nguyen tac trien khai UI/UX
- Thong tin uu tien theo quyet dinh dat san (ten san, dia diem, slot trong, gia, CTA).
- Moi man hinh co loading/empty/error state ro rang.
- CTA chinh luon thay de nhin tren mobile.
- Trang thai booking/payment phai de hieu voi nguoi dung, khong technical wording.

## Out of scope cho MVP
- Chatbot booking.
- Loyalty/gamification.
- Dashboard bao cao nang.
- Social login nang cao.
