# Frontend User Journey (MVP)

Ngay cap nhat: 2026-04-15

## Journey chinh
1. User vao Home, nhap tim kiem nhanh (dia diem/sport/ngay/gio).
2. User vao listing da co san filter tu Home.
3. User mo chi tiet dat lich (booking grid), chon slot trong.
4. He thong tao draft booking va hien summary.
5. User dang nhap neu chua co session hop le.
6. User thanh toan coc/full.
7. User nhan trang thai thanh toan va booking confirmation.
8. User xem lai booking trong My Bookings.

## Rule UX bat buoc
- Khong lam mat context khi user bi buoc dang nhap.
- Trang thai loading/empty/error phai ro rang o moi buoc.
- CTA chinh phai nhin thay de tren mobile.
- Khong dung message technical de hien thi cho end user.
